# LAVS 范式设计书：学·行·核·结（Thought/Action/Observation 的抗漂移替代）

> 定位：替换 ReAct 的 T/A/O 循环层；**现有工作流全部保留**（LRV＝认知内核，apprentice 资产＝记忆与门，da_toolbox/lrv.py＝机械执行体）。
> 设计原则：**思不出环，环环外锚**——漂移的入口不是某个环节算错，而是"思考"作为自由原语存在（无出处、无检验、继承全部历史漂移）。

## 一、动机：T/A/O 的六个漂移源（要逐个封死）

| # | 漂移源 | 在 ReAct 中的表现 | LAVS 对策 |
|---|---|---|---|
| 1 | 信念漂移 | Thought 基于自建上下文推理，越推越自信 | 思不出环：思考只存在于 L（带源提问）与 S（合卷总结），且必被 V 检验 |
| 2 | 确认偏误 | Observation 由模型自由解读，解读被先验污染 | V 是**结构化比对**（对任务规格/对知识基准），不是自由解读 |
| 3 | 目标漂移 | 无全局锚，长任务跑着跑着忘了初衷 | 里程碑门＋**目标对齐巡检**（原目标 vs 累积产出） |
| 4 | 上下文腐化 | 长程 context rot，早期信息稀释 | S 外置沉淀，环间靠门＋台账延续，**环可重启上下文** |
| 5 | 失败螺旋 | 失败→再 Thought→在漂移的地基上重试 | 失配→**缺口登记簿**（外置债务）→下环 L 定向学，不进上下文进台账 |
| 6 | 无限打转 | 无终止保证，同类错误循环 | 机械重试上限（3 次）＋门 DoD＋satisficing（学够即行） |

## 二、范式定义：LAVS 四节点

```
        ┌────────────── 长程任务（规格书）──────────────┐
        │   里程碑 M1 ── 门1 ── M2 ── 门2 ── … ── 终验   │
        └───────┬──────────────────────────────┬───────┘
                ↓ 每里程碑内循环：                 
        L 学（思入）→ A 行 → V 核 → S 结（思出）
         ↑__________________缺口回喂__________________↓
```

### L · 学（Learn-acquire）——思考的第一形态：带锚的输入思考
- 思考在此的合法形式：**提问式加工**（对材料带 3 问读）＋**方案设计**（设计单：做什么/凭什么/对什么验）；
- 锚：材料必须来自外部源（权威源/环境数据）或已验证自库——**禁止以"我想到"为论据**；
- 内嵌 LRV 认知模：L 即 LRV 的 L；知识型单元到此为止，直接走 LRV 全环。

### A · 行（Act）——纯执行，无内联自由思考
- 只执行 L 产出的已锚定方案；**A 内禁止自由推理**（执行中发现"更好的想法"不算数）；
- 异常处理协议：遇到意外 → 捕获观察快照 → 中止本环节点；
- 机械重试豁免：纯技术性失败（文件占用/超时类）可重试，**同类失败 ≤3 次必须回环**（防打转）。

### V · 核（Verify）——结构化比对，双位核验
- **任务位**：产物 vs 任务规格/里程碑验收线（对拍已知答案、复现标准）；
- **知识位**：本轮涉及论断 vs 基准（E 共识／M 自库混合／L 自结论——LRV 的 V 直接复用）；
- V 只产出三类结果：通过／失配清单（分级＋归因）／门状态更新——**不产出"新想法"**。

### S · 结（Summarize-settle）——思考的第二形态：被检验过的输出思考
- 思考在此的合法形式：**合卷总结**（不看过程材料复述本环学到了什么/做成了什么）＋**归因**（成败各归到规则级）＋**规则提炼**（失效→新红线）；
- 沉淀四出口（外置记忆，本环上下文此后可丢弃）：概念卡（语义）／SOP 与红线（程序）／能力画像与门状态（状态）／缺口簿（债务）；
- S 即 LRV 的 R＋产物归档的合并位——**环的终点是台账，不是上下文**。

## 三、双环结构：LAVS 外环 × LRV 内核（兼容声明）

- **LRV 不变**：认知型单元在 L 节点内走完整 LRV 循环（学→述→验），LAVS 只是在其外包了行动与任务核验；
- **apprentice 不变**：四阶段＝领域级长程 LAVS 实例（阶段门＝里程碑门，验收组＝V 的任务位，RSI＝LAVS 环链），本范式是它的机制层显式化；
- **工具不变**：门＝da_toolbox `gate/check`；缺口簿＝`gap`；里程碑状态＝`profile`；LRV 轮次＝lrv.py——LAVS 是编排层，不新增执行体（第一期）。

## 四、长程任务协议（用户点名要求）

1. **任务规格书**（开工必立）：目标一句话／不可变约束（红线）／里程碑 Mn 及各自验收线／终止条件／止损线；
2. **里程碑门**：每 M 一道机械 DoD，不过门不进下一 M（状态外置，上下文可重启）；
3. **目标对齐巡检**（防 goal drift）：每 N 环（建议 5）做一次——原始目标 vs 累积产出 vs 当前计划三方比对，偏差＞阈值即回炉（重读规格书＋缺口归零重排）；
4. **环内终止**：V 全通过＋S 沉淀完成＝本环闭合；里程碑通过＝段闭合；规格书终止条件满足＝任务闭合。

## 五、漂移量化（agent 健康面板四指标）

| 指标 | 定义 | 健康线 |
|---|---|---|
| 环失配率 | V 失配数/核验条数，按环时间序列 | 稳定或下降 |
| 门重试数 | 每里程碑的门重开次数 | ≤2 |
| 对齐偏差 | 巡检时累积产出与原目标的偏离度量 | ≤阈值（任务书定） |
| 校准误差 | 独立考官抽检 vs 自检结论的差值（E/M/L 各测） | L 期≤M 期≤E 期 |

## 六、ReAct ↔ LAVS 映射

| ReAct | LAVS | 变化本质 |
|---|---|---|
| Thought | 拆入 L（提问式）与 S（总结式），被 V 强制检验 | 自由原语→锚定原语 |
| Action | A（禁止内联思考＋机械重试上限） | 不变其形，锁死其边界 |
| Observation | V（结构化比对：对规格/对基准） | 自由解读→受控核验 |
| （无） | S＋外置台账＋门 | 新增：状态外置与沉淀 |
| （无） | 目标对齐巡检/独立考官 | 新增：全局锚与外锚 |

## 七、最小实现路径（三期）

- **一期（最小可用）**：LAVS 编排协议＋任务规格书/里程碑门模板＋"A 禁思考/重试≤3"的会话纪律——纯协议层，零新代码，现有 lrv.py/da_toolbox 直接承载；验证标准：一个长程任务全程按 LAVS 跑完，四指标留痕；
- **二期（技能模）**：LAVS 的 V 扩环境验证通道（产物对规格/环境执行结果），S 增加程序记忆出口（技能卡）；
- **三期（锚定制度）**：独立考官抽检＋校准误差面板＋定期回炉排程，L 期才真正敢放手跑。

## 八、红线

1. 思不出环——A 与 V 内禁止自由推理，"想到的"必须回 L 立案；
2. 环环外锚——每环 V 至少一次外部基准（E 级）；
3. 失配入簿不入上下文（漂移的债务化管理）；
4. 同类机械重试 >3 次即回环；
5. 无规格书不开工（长程任务）；
6. 环的终点是台账不是上下文（S 沉淀完成前不许开新环）。
