# 学述验闭环（LRV Loop）

AI 自学的最小闭环引擎，结构对标 ReAct：

| | ReAct | LRV（本组件） |
|---|---|---|
| 循环 | 思考 → 行动 → 观察 | **学习 → 复述 → 验证** |
| 驱动目标 | 完成外部任务 | **完成一次知识的内化** |
| 终止条件 | 任务达成 | 复述通过验证（零关键失配＋覆盖率达标） |
| 反馈信号 | 观察结果修正下一步行动 | **失配清单成为下一轮学习靶点** |

## 一、三步协议（每轮必走全三步，缺一即退化）

### L · 学习（Learn）——允许查源
- 带问题输入：主动生成或继承 3 个待答问题，分层读材料（综述→精读→按需下钻）；
- 产出学习笔记（允许摘抄、允许查源查卡），标注本轮覆盖的知识点清单。

### R · 复述（Restate）——**强制合卷**
- 合上全部材料与卡片库，仅凭记忆输出复述稿，固定结构：
  1. 术语复述：本轮知识点逐一定义＋举例；
  2. 结构复述：知识点之间的关系（层级/依赖/对立）；
  3. 机制复述：它为什么成立、怎么用、何时失效；
- **记不起的地方必须显式写"〔记不起〕"，禁止凭感觉编造填补**——复述稿是检索练习，不是表演；
- 卡壳点逐条标记（这些就是验证环节的重点比对区）。

### V · 验证（Verify）——逐条对源比对
对复述稿做三层 diff，逐条给出失配判定：

| 比对层 | 检查什么 | 失配分级 |
|---|---|---|
| 事实层 | 定义、数值、术语、出处对不对 | 关键失配（概念错）/ 次要失配（表述不准） |
| 结构层 | 关系、层级、分类对不对 | 遗漏（漏了知识点）/ 错挂（关系摆错） |
| 理解层 | 机制、适用域、失效条件讲没讲对 | 误解（最严重）/ overclaim（讲过头） |

- 每条失配**必须归因**：未学（材料没覆盖）/ 学了忘（检索失败）/ 误解（错误内化）——不同归因对应不同下一轮动作；
- 覆盖率＝复述命中知识点 / 本轮知识点清单；
- **通过标准：零关键失配（含零误解）且覆盖率 ≥80%**。

### 轮次循环
V 的失配清单＝下一轮 L 的靶点——**只学缺口，不重读全量**（间隔检索由轮次天然实现）。通过后 `lrv.py round pass` 锁档，模块状态→已通过。

## 二、验证基准的期别演进（本组件的核心机制）

验证"和什么比"不是固定的，随学习者可信度成长而演进——这是"验证结果从行业共识变成自己的结论"的制度化：

| 期别 | 验证基准 | 解锁条件 | 附加义务 |
|---|---|---|---|
| **E 共识期**（默认） | 权威源原文（教材/综述/行业共识/NIST 类验证数据），逐条引用 | 无，新模块一律从 E 开始 | 基准引用必须落到可核对出处 |
| **M 混合期** | 双基准：①自己已验证的概念卡库 ②权威源——两者都要过 | 全项目 ≥2 个模块经 E 期验证通过 | 自库条目须注明其原始验证出处（信任是链式的） |
| **L 自主期** | 自己的结论体系（已验证结论互洽性检验） | 全项目 ≥5 模块通过 且 本模块有 M 期轮次记录 | **矛盾升级条款：复述与任一既有已验证结论冲突时，冲突双方一并降回共识期复核**——防止自洽的错觉固化成体系性错误 |

解锁条件由 `lrv.py` 机械强制（不满足拒绝记录该基准的轮次），阈值可按项目调整。

**为什么这样设计**：自己的结论能当验证基准，前提是它曾用共识挣到过信任（E/M 期履历），且永远保留被矛盾触发回炉的通道——"自主"不是免检，是信用等级。

## 三、日志与工具

每模块一份日志 `研究档案/LRV/<模块名>.md`，每轮固定五节：**学习输入 / 复述稿 / 验证 diff / 失配清单与归因 / 裁决与下一轮靶点**。工具 `scripts/lrv.py`（stdlib 单文件）：

```
lrv.py init <项目根>                        # 初始化状态库
lrv.py round add <根> <模块> --basis E|M|L --coverage 0.8 --major 0 --minor 2 --missing 1
lrv.py round pass <根> <模块>               # 通过锁档（更新解锁进度）
lrv.py status <根> [--module <模块>]         # 轮次史+当前各期别解锁状态
lrv.py check <LRV日志.md>                   # 校验五节齐全（机械安检）
```

`round add` 会校验该 basis 是否已解锁（未解锁 exit 2 并说明差什么），并自动补建模块日志骨架。

## 四、接入契约（与学徒 Skill apprentice 的对接）

lrv-loop 是**外挂组件**，apprentice 以插件方式接入，双向都不覆盖对方本体：

| LRV 产物 | 回喂 apprentice 的资产 |
|---|---|
| 通过的复述稿 | 课程表模块"已通过"依据＋费曼记录 |
| 失配清单（未销） | 缺口登记簿新条目 |
| 轮次统计 | 能力画像（学习维度的实证数据） |
| 复述中提炼的新概念 | 概念卡库增量 |

- **apprentice 侧接入点**：通识轨模块学习循环（学→织→测→联）中的"学＋测"两步由 lrv-loop 驱动；
- **缺席降级**：lrv-loop 未安装时，apprentice 按内置 `references/learning-prompts.md` 模板二/三/四手工执行同等协议，流程不断；
- **独立运行**：脱离 apprentice 也可单独用（任何学习任务套 L-R-V 三步即可）。

> **范式扩展（LAVS）**：以本组件为认知内核的 agent 编排范式见 `references/paradigm-LAVS.md`——学(L·思入)→行(A·纯执行)→核(V·双位比对)→结(S·思出沉淀)四节点替换 ReAct 的 T/A/O，设计原则"思不出环，环环外锚"，含长程任务协议（规格书/里程碑门/目标对齐巡检）与漂移量化四指标。

## 五、红线

1. 复述必须合卷——开着材料"复述"等于没测；
2. 记不起必须显式标注，禁止编造填补；
3. 验证必须逐条对源，禁止抽样比对；
4. 失配不归因，不得进入下一轮；
5. 期别解锁条件不可跳过；L 期结论与既有结论矛盾时双方强制降回共识复核；
6. 无日志不认轮次（跑过但没落档＝没跑）。
