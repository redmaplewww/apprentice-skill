# 学徒 Skill（Apprentice）

> AI 从零进入并精通任意陌生领域的标准作业程序——不是"查资料"，而是**学会一个领域**。

**Apprentice** 是一套给 AI 编码智能体（ZCode / Claude Code 等）的领域学习 Skill：让 AI 像学徒一样进入一个全新领域——拜师学规矩（把行业共识翻译成 SOP）、模仿练手（已知答案盲测验收）、师傅考核（独立审核＋行业共识对拍）、出师执业（RSI 自循环批量作业）——直到产出经得起审查的成果。

方法论源自一次完整实战：**甲骨文 AI 辅助破译**（六轮循环、145,072 字形全量入库、验收组 5/5 复现学术定论、21 卡独立盲审），随后又在两个认识论完全不同的领域（计量文体学·统计指纹、金属分子动力学·数值实验）完成通用性验证。

## 双轨 × 四阶段

```
通识轨（懂领域）——领域课程六类模块 → 学→织→测→联（概念卡/费曼/自测/跨模块）
      ║ 两轨强制互喂：模块知识喂实战证据链；实战缺口回课程补模块
实战轨（会做事）——四阶段任务闭环：

阶段一 侦察立法          阶段二 最小闭环          阶段三 审查对拍          阶段四 RSI自循环
调研现状/资源/方法论 → 固化SOP+预留AI接口
                    盲测校准+已知答案验收组(≥80%)
                                        独立审核(制审分离)+行业共识对拍+诚实定性
                                                            循环:选目标→批量作业→审核→规则升级
```

每阶段有**验收门**（DoD 未达标不得升级），双轨 DoD 同时达标才开门。

## 十二条铁律（节选）

① 可核查性压倒一切（结论落到原始材料，记忆性证据标"待核对"）② SOP 从行业共识翻译而来，不由 AI 发明 ③ 已知答案验收是唯一硬标准 ⑦ 错误变制度，同类错误不犯第二次 ⑧ 诚实定性：复现 ≠ 新发现 ⑩ 来源三级标注（已验证/待核对/未知缺口），禁止用记忆填充冒充知识 ⑪ 能力边界自知：未测试＝未知 ⑫ 案例是学习仪器不是目的——每案回喂课程。

## 知识完整性与防乱答

行业知识七形态中只有"模型权重里的隐性记忆"不可证（乱答唯一来源）。对策：权威普查工件对照算覆盖率、任务空间地图×分层抽测×能力画像、答前门控三问、缺口驱动学习循环（巡检→登记→定级→补缺→复测销账）。

## 安装

```bash
git clone https://github.com/redmaplewww/apprentice-skill.git
# ZCode / Claude Code 通用技能目录（用户级，全项目可用）：
cp -r apprentice-skill/apprentice ~/.agents/skills/apprentice
# 或项目级：cp -r apprentice-skill/apprentice <你的项目>/.agents/skills/apprentice
```

触发：对 AI 说"让 AI 上手/学会 XX 领域"、"领域开荒"、"建立 XX 领域工作流"、"系统学习 XX"，或直接 `/apprentice`。

## 典型用法

```
用户：用学徒 Skill 让 AI 掌握金属分子动力学计算
 → 阶段一：AI 调研领域现状/权威资源/方法论体系，产出五件套（含知识总账与课程表）
 → 阶段二：语料入库+已知答案盲测验收（如对拍 NIST 标称值）≥80%，SOP 升级
 → 阶段三：独立审核代理从原始数据盲审+行业共识对拍，红线固化
 → 阶段四：RSI 循环批量作业，每案回喂课程，能力画像滚动生长
```
