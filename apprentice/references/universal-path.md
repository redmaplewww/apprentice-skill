# 通用自学路径：从零进入任意新领域（可复现操作手册）

> 配套可视化：`assets/学习路线图.html`（Part 2 即本手册的流程图版）。
> 本手册与领域无关，任何领域照此执行；领域特殊性只体现在各节"备注"和文末对照表。与 skill 四阶段的关系见文末映射表——两套流程同源，本路径偏人类自学者，skill 偏 AI 作业，可互相翻译。

## 结构总览

**六阶段主干**（P0 定向 → P1 侦察 → P2 筑基 → P3 校准 → P4 实战 → P5 创造）× **三横支撑系统**（S1 元认知 / S2 知识管理 / S3 动机精力，全程并行）× **五道验收门** × **五条回环**。非线性流水线：回环是预期行为，不是失败。

## P0 定向——学前决策

- [ ] 三问定标：为什么学（内在/外在）？学到什么程度（了解/会用/精通/前沿）？时间预算（每周几小时 × 几个月）？
- [ ] 写学习宪章（一页纸）：目标 / 验收标准（可检验）/ 止损线（何时允许放弃）/ 节奏承诺
- [ ] 预演失败：三个月后若放弃，最可能的三个原因 + 对策
- **验收门 ⓪**：一句话说清"为什么学 + 学到什么算成"，验收标准可被第三方检验
- 常见坑：目标过大、无验收标准、无止损线
- *备注（特殊性）*：验收标准的形态因领域而异——甲骨文＝释读档案达论证格式；编程＝独立交付上线项目；语言＝专业话题流畅交流*

## P1 侦察——信息搜集（画地图）

- [ ] 广度扫描：百科 / 高引综述 / 经典教材目录，≥3 个独立来源交叉（防单源偏见）。**本阶段禁深读**
- [ ] 画领域全景图：子领域 · 主流流派及分歧 · 经典问题 · 活跃前沿 · 标杆人物与机构
- [ ] 建术语表：50–100 核心术语 + "术语 ↔ 白话"对照
- [ ] 权威源分级：★★★ 核心（教材/综述/标杆社区）/ ★★ 专题 / ★ 补充，记录可信度理由
- [ ] 搭信息管道：剪藏 / 稍后读 / RSS / 知识库 Inbox——信息流向固定位置，不散落收藏夹
- **验收门 ①**：徒手画领域地图；说出 3 个流派/经典问题；知道问题该去哪个社区问谁
- 常见坑：陷入细节、仓鼠症（只收藏不处理）、单源依赖

## P2 筑基——结构化输入（搭骨架）　↩ 可回 P1

- [ ] 分层阅读（自顶向下）：综述 → 教材主干 → 专题章节 → 一手文献；先通读建框架再按需下钻，禁线性从头读到尾
- [ ] 主动阅读（SQ3R 变体）：读前写 3 个问题 → 带问题读 → 合书自答 → 复述 → 隔日回顾
- [ ] 概念织网：卡片笔记（一卡一事：术语/概念/原理/方法）+ 定期画概念地图，新知挂网
- [ ] 费曼自测：每章向假想新人讲一遍，卡壳处标记回炉
- [ ] 间隔重复排程：核心概念入卡片系统（1/3/7/21 天递进）
- **验收门 ②**：费曼测试——向外行讲清核心概念及关系，被追问三层不倒
- 常见坑：划线式假阅读、收藏=学会错觉、线性阅读强迫症

## P3 校准——刻意练习（已知答案闭环）　↩ 可回 P2

- [ ] 选已知答案案例集：教材习题 / 经典复现 / 有定论问题；过程要求与真实任务完全一致
- [ ] 独立作答：不看答案全流程走完（边看边做＝自欺）
- [ ] 对照打分 + 失效归因：知识缺口（回 P2）/ 方法缺陷（改流程）/ 熟练度（多练）
- [ ] 错题本：错误 → 规则，每条失效转成显式规则
- [ ] 难度爬坡：维持约 85% 正确率区间，逐级加码
- **验收门 ③**：已知案例复现率 ≥80%（或领域公认线），失效已全部转化为规则
- 常见坑：看答案再做、只做舒服题、只对答案不归因

## P4 实战——项目驱动（真实产出）　↩ 可回 P1/P2

- [ ] 选真实约束项目：真实数据 / 真实受众 / 真实交付标准，规模适中但非玩具
- [ ] 以终为始：先定交付物，倒推能力清单——每课有去处
- [ ] 建反馈回路：行业标准对照 · 社区评审（发到内行看得到的地方）· 专家请教（带具体问题）
- [ ] 卡壳定向补课：回环预期内，定向补而非重学
- [ ] 过程留档：决策日志（为什么这么做）——P5 素材 + 复盘依据
- **验收门 ④**：作品经得起行业标准 / 第三方评审
- 常见坑：教程地狱、完美主义憋大招、无反馈裸奔

## P5 创造——内容创作与贡献（出师）　↩ 可回 P2/P3

- [ ] 输出金字塔：学习笔记 → 教程/文章 → 工具/项目 → 原创贡献，逐级公开
- [ ] 教学相长：写作 / 演讲 / 带新人 / 答疑（备课逼你补全每个含糊处）
- [ ] 跨域重组：领域 A 框架类比到领域 B，找自己的视角
- [ ] 社区身份进阶：提问者 → 回答者 → 协作者 → 组织者；知识资产长期沉淀
- [ ] 诚实定性：区分复现 / 归纳 / 原创；引用规范
- **验收门 ⑤**：公开输出获得领域内真实反馈 / 引用 / 认可（被内行认真对待）
- 常见坑：憋大招不发布、复读式无增量创作、闭门造车

## 三横支撑系统（全程并行）

**S1 元认知（思考学习）**：每日三行学习日志（学了什么/卡在哪/明天怎么办）· 周复盘 KPT（Keep/Problem/Try）· 定期三问（我在哪/要去哪/方法有效吗）· 费曼检测排程 · 目标再校准（→ 回 P0 改宪章，含主动放弃决策）

**S2 知识管理**：收集（一元化 Inbox）→ 蒸馏（提炼成卡）→ 归档（主题化）→ 召回（检索+间隔复习）。原则：一切笔记落到可核查出处。结构：术语卡/概念卡/案例卡/方法卡。P5 的创作从卡片长出。

**S3 动机精力**：进度可视化（总进度文档/里程碑打卡）· 小成果早发布 · 同伴与社区公开承诺 · 止损线与休整（防沉没成本、防倦怠）

## 回环机制汇总

| 回环 | 触发 |
|---|---|
| P2 → P1 | 发现资源缺口 / 单源偏见 |
| P3 → P2 | 错误归因为知识缺口 |
| P4 → P1/P2 | 实战暴露基础缺口（预期内） |
| P5 → P2/P3 | 教学/创作暴露盲区 |
| S1 → P0 | 目标再校准（领域/兴趣/进度变化） |

## 八条通用模式（跨领域不变量）

1. 地图先行（广度优先，先框架后细节）
2. 结构化输入（分层阅读+概念织网）
3. 已知答案校准（量化真懂，对抗感觉学会）
4. 真实项目产出（以终为始）
5. 输出倒逼输入（费曼/教学/创作）
6. 全程反馈回环（元认知+独立审查+共识对拍）
7. 错误变制度（错题本/红线）
8. 知识可核查（出处落地，区分验证过与听说的）

## 与领域学徒 skill 的映射（同源对照）

| 通用路径 | 领域学徒 | 学习科学原理 |
|---|---|---|
| P0 定向 | 冷启动确认 | 自我调节学习·前思（Zimmerman） |
| P1 侦察 | 阶段一·侦察立法 | 先行组织者（Ausubel） |
| P2 筑基 | SOP v1+数据基建 | 图式建构、精细加工 |
| P3 校准 | 阶段二·最小闭环 | 测试效应、合意困难（85% 规则） |
| 反馈回路 | 阶段三·审查对拍 | peer review、外部校准防自欺 |
| P4 实战 | 阶段四·RSI 循环 | 刻意练习（Ericsson） |
| P5 创造 | 成果沉淀+对外输出 | 门徒效应 |
| S1 元认知 | 总进度+门控 | 元认知监控（Flavell） |
| S2 知识管理 | 铁律①可核查 | 生成效应、反幻觉 |
| 错题本 | 铁律⑦错误变制度 | 高校正效应（hypercorrection） |
