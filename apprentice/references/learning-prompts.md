# 通识轨学习提示词模板集

> 配套 SKILL.md"通识学习轨"章节使用。每个模块开课时按对应模板执行；产出全部落 `研究档案/概念卡库.md` 与 `领域课程表.md`，引用一律带出处，未核实标〔待核对〕。
> 使用方式：把【材料】替换为实际输入后，作为该环节的固定作业指令执行。

## 模板一：概念卡生成（织网的基本单元）

```
【角色】你是领域学徒，正在为<领域>建立概念卡库。
【材料】<术语/概念>及其出处材料（教材章节/论文段落，附来源）。
【任务】输出一张概念卡，固定结构：
1. 术语：<中文>（<原文/别名>）
2. 定义：<一句话，注明出处；材料中没有的禁止自己编，标〔待核对〕>
3. 例子：<1 个正例>；反例：<1 个最易混淆的近邻概念，说明区别>
4. 上位/下位/平行：<在知识地图上的挂网位置，与哪些已入库概念相连>
5. 常见误解：<初学者最常犯的理解错误>
【红线】定义必须有出处；与相邻概念的区别写不清＝没懂，退回重学。
```

## 模板二：模块学习（每个课程模块的主循环）

```
【角色】你是领域学徒，开始学习课程模块<模块名>（第 N/六类）。
【材料】<挂接的本模块资源清单：综述→教材章节→专题，按序>。
【任务】
1. 读前先写 3 个问题（我期望这个模块回答什么）；
2. 分层读完（综述通读→章节精读→专题按需），逐条回答 3 问；
3. 产出本模块要点结构（≤1 屏：核心问题/关键概念/方法谱系/适用域与失效条件）；
4. 概念卡增量：<新概念逐张按模板一入库，更新知识地图挂网>；
5. 标出卡壳点：<哪里讲不顺、哪里存疑，留待费曼环节验证>。
【验收】3 问全部有答案；要点结构能脱稿复述。
```

## 模板三：模块自测（出题+对答案，测试效应）

```
【角色】你是领域学徒的自我考官。刚学完模块<模块名>。
【任务】
1. 从本模块材料出 8 道考题（4 概念辨析 + 2 方法适用判断 + 2 综合应用），
   出题依据仅限已入库材料，逐题标注出处；
2. 合卷作答（闭卷：不看材料凭卡片库作答）；
3. 对答案逐题判分，算通过率；
4. 失效归因：错题归为 知识缺口（回模块重学）/ 误解（更新概念卡"常见误解"栏）/
   出题歧义（重出）三类；
5. 通过率 ≥80% → 模块状态改"待测"（等费曼）；<80% → 回学，重考一次。
【输出】考卷+答案+判分+归因表，附于课程表该模块之下。
```

## 模板四：费曼讲解（通识轨的最终验收）

```
【角色】你是一位对本领域零基础的聪明人，我是刚学完模块<模块名>的领域学徒。
【任务】我向你讲解本模块：核心问题是什么、关键概念如何串起来、一个例子走到底。
【执行】
1. 讲解全文（不用行话，必须用行话时当场定义）；
2. 自查卡壳清单：<每个讲不顺/只能背定义的地方逐条列出>；
3. 卡壳点回炉：<针对性重学并更新概念卡>，直至卡壳清零；
4. 给自己出 2 个"追三层"问题并回答（为什么？再为什么？）。
【验收】卡壳清零 + 三层追问不倒 → 模块状态改"已通过"。
```

## 模板五：周复盘（元认知，S1 系统的落点）

```
【任务】对本周学习做 KPT 复盘：
- Keep：<本周什么学习方法有效，下周保持>
- Problem：<哪里卡住/失效/偏离课程表>
- Try：<下周尝试的具体改变（可验证的，不是口号）>
附三问自答：我在课程表哪个位置？离下一道门还有几个模块？实战轨与通识轨是否失衡
（本周只做题没学习/只读书没实操都算失衡）？
【输出】≤10 行，追加到 00-总进度.md 本轮记录之下。
```

## 模板六：跨模块联想（知识地图织网＋两轨互喂）

```
【任务】在概念卡库中做一次跨模块扫描：
1. 连接：新学模块与已通过模块之间，哪些概念存在<同构/类比/依赖/对立>关系？
   逐条挂到知识地图（A—关系—B）；
2. 冲突：两个模块对同一问题的说法是否矛盾？矛盾点登记为缺口（源分歧信号）；
3. 互喂清单：
   - 通识→实战：<本模块哪个知识点应当改进 SOP/证据权重/红线>；
   - 实战→通识：<近期实战案例暴露了我哪个模块知识的欠缺，回炉哪个模块>。
【输出】联想记录入概念卡库末尾"跨模块联系"节；互喂清单写入课程表。
```

## 使用纪律

- 模板三是硬门：没有自测记录的模块不算学过；
- 模板四卡壳清零才算"已通过"——背定义≠理解；
- 模板六每学完一个模块跑一次，防止课程表变成六座孤岛；
- 所有产出带出处与日期，供独立审核抽查（审核者可抽任意概念卡要求当场复述）。
