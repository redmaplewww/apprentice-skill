Part 1 · 学徒 Skill 的学习路线与方法AI 进入新领域的四阶段标准作业程序

原型：甲骨文 AI 辅助破译项目（六轮实战验证）。核心思想：AI 是学徒，行业共识是师傅——SOP 从行业方法翻译而来，不由 AI 发明；每阶段有验收门，未达标不得升级。

通识轨（懂领域）——领域课程学习循环

  • 六类标准模块：基础概念 → 理论方法 → 工具实践 → 历史流派 → 经典公案 → 前沿开放
  • 每模块循环：学（带3问分层读）→ 织（概念卡+地图挂网）→ 测（自测≥80%）→ 联（跨模块+互喂）
  • 验收：自测＋费曼卡壳清零双过才算"已通过"；审核环节含"领域讲解"考核

实战轨（会做事）——四阶段任务闭环（本图主体）

  • 侦察立法 → 最小闭环 → 审查对拍 → RSI 自循环（每阶段嵌入对应通识模块）
  • 两轨强制互喂（铁律⑫）：模块知识喂实战证据链；实战缺口回课程补模块；每案结档必回喂课程
  • 禁止"只会做题不懂领域"，也禁止"懂名词不会干活"
第零步 · 阶段定位（每次触发先做） 检查工作区已有文档与总进度 → 判断当前所处阶段 → 从对应阶段进入，不从头重来；全新项目则冷启动（先确认：领域名、目标产出、验收标准谁定）
阶段一

侦察立法

广泛调研 + 文献调研 → 固化标准 SOP + 预留 AI 接口
  1. 领域现状报告：现状与难点 / 前人工作全景 / AI 能做什么不能做什么（定位通常＝全量材料的机器检索+组合推理，人做最终裁决）
  2. 资源清单：数据集、平台、文献，按 ★★★核心 / ★★支撑 / ★补充 分级，附来源与许可证
  3. 方法论体系（SOP 的灵魂）：解剖 2–4 个标杆从业者案例——他们靠什么证据下结论、证据如何加权
  4. SOP v1：端到端流程拆阶段，每步写明输入→输出 / 工具 / 执行者（人工·AI·协同），附固定作业模板
  5. 接口预留：数据（结构化入库可检索）/ 工具（一次性脚本不服务化）/ 记忆（进度文档＋mem0）/ 分工（每步标注，逐步自动化）

产 出

现状报告 · 资源清单 · 方法论体系 · SOP v1

学习法注解

＝先看地图再上路（广度优先）
＝把师傅的口传心授写成操作手册

常见坑

忍不住提前做真任务；调研引用不带来源；SOP 由 AI 凭空发明而非翻译行业共识
◆ 验收门 1：五件套齐备（现状报告/资源清单/方法论体系/SOP v1/知识总账）未达标 → 留在本阶段补齐
阶段二

最小闭环

典型案例盲测 + 已知答案验收 → 跑通最小闭环↩ 可回阶段一
  1. 材料基建：核心数据下载、清洗、切分、元数据、检索索引；入库即写统计报告与数据质量坑
  2. 盲测校准：已知答案样本匿名打乱，用当前 SOP 独立作答，量化命中率——重点不是分数，是失效模式逐条转化为新规则
  3. 验收组：选 3–5 个有公认标准答案的案例，走与真实任务完全相同的流程，最后对照标准答案打分
  4. SOP 升级 v2：证据分级加权表（裁决性 / 入门券 / 支撑 / 跃迁桥 / 先验缩域 / 可证伪）＋裁决规则＋五档置信度

产 出

结构化语料库 · 盲测校准报告 · 验收报告 · SOP v2

学习法注解

＝摸底考（盲测）
＝做真题对答案（验收组）
＝错题本（失效→规则）

常见坑

降低验收标准放行自己；只看分数不分析失效根因
◆ 验收门 2：验收组复现率 ≥80%（或与用户约定线）不达标 → 回修 SOP 再来，禁止带病升级
阶段三

审查对拍（出师考核）

可控人工审查 + 行业共识对照 → 确认真懂↩ 可回阶段二
  1. 独立审核（制审分离）：审核者与制档者分离；审核者禁止采信档案文字，必须从原始数据独立查证；禁止自我放行。重点揪三类病：证据描述失实 / 引文加工与选择性引用 / 置信度 overclaim
  2. 整改与红线固化：逐条整改 → 系统性问题升格为红线写进 SOP（图像二次核对 / 残缺禁补写 / 主导模式强制展示 / 同源完整上下文强制调取 / 审核后定稿）
  3. 行业共识对拍：已认定结论与已发表权威成果逐条对拍；被推翻就改，教训固化（对拍先于发布）
  4. 诚实定性报告：复现 ≠ 新发现；标注哪些是复现、哪些是增量、距行业认可标准差什么（差距清单）

产 出

独立审核报告 · 整改记录 · 对拍报告 · 诚实定性报告 · SOP v2.1+（红线）

学习法注解

＝请老师盲批（审核者不看你的答案自己查）
＝和标准答案对拍
＝出师资格考试

常见坑

审核者复读档案（假审）；审核是走形式，不挤水分
◆ 验收门 3：独立审核通过（无未整改系统问题）＋ 对拍完成 ＋ 定性报告出具此门过后才有资格进入无人值守 RSI 循环

▎十一条通用铁律（全阶段贯穿，Part 2 通用路径同样成立）

① 可核查性压倒一切（结论落到原始材料，记忆性证据标"待核对"）② SOP 从行业共识翻译而来，不由 AI 发明 ③ 已知答案验收是唯一硬标准 ④ 先易后难 ⑤ 置信分档输出，降档不可耻 ⑥ 淘汰不丢（否决假设归档防重复劳动）⑦ 错误变制度，同类错误不犯第二次 ⑧ 诚实定性：复现 ≠ 新发现 ⑨ 对拍先于发布 ⑩ 来源三级标注：〔已验证·有出处〕/〔模型记忆·待核对〕/〔未知·缺口〕，"未知"必须显式声明，禁止用记忆填充冒充知识 ⑪ 能力边界自知：未测试任务类型＝能力未知，超纲即降档并触发补缺，禁止硬答

▎贯穿机制 · 知识完整性与缺口管理（会做题 ≠ 行业能力；乱答只来自隐性知识）

行业知识的七种存在形态载体可信度
① 程序性（怎么做）SOP 工作流文档高（经审核）
② 判别性（凭什么下结论）方法论体系 / 证据权重表高（译自行业共识）
③ 事实性（原材料）结构化语料库高（原始材料）
④ 案例性（这题怎么解的）单案研究档案中–高
⑤ 失败性（什么会错）红线 / 错题本 / 已排除假设高
⑥ 元知识（进展/缺口/教训）总进度 / 总账 / 登记簿 / 画像高
⑦ 领域通识（背景直觉）模型权重（隐性）不可证 ← 乱答之源
对策不是"让模型不乱答"，而是逼每条论断声明来自哪一行。供应侧完整性靠权威普查工件对照（教材目录/考纲/分类总录/数据集类目/招聘JD/社区FAQ 逐区 diff 出覆盖率）；真实能力靠任务空间地图（类型×难度）+ 分层抽测 + 能力画像度量，未测试＝未知。

Part 2 · 通用自学路径：从零进入任意新领域参考人类学习流程提炼，领域无关、可复现

主干六阶段（P0–P5）＋三横支撑系统（全程并行）＋五道验收门＋五条回环。任何领域照此路径均可复现；领域特殊性只体现在各节点备注（见 Part 4），主干结构不变。

S1 · 元认知系统（思考学习，全程并行）

  • 学习日志（每日三行：学了什么 / 卡在哪 / 明天怎么办）
  • 周复盘 KPT：Keep 保持 · Problem 问题 · Try 尝试
  • 定期三问：我在哪 / 要去哪 / 当前方法有效吗
  • 费曼检测排程：讲不清 = 没懂，标记回炉
  • 目标再校准 → 触发回 P0 改宪章

S2 · 知识管理系统（全程并行）

  • 流程：收集（一元化 Inbox）→ 蒸馏（提炼成卡）→ 归档（主题化）→ 召回（检索＋间隔复习）
  • 原则：一切笔记落到可核查出处
  • 结构：术语卡 · 概念卡 · 案例卡 · 方法卡
  • 产出反哺：P5 的内容创作直接从卡片长出

S3 · 动机精力系统（全程并行）

  • 进度可视化：总进度文档 / 里程碑打卡
  • 正反馈设计：小成果早发布（S5 会前移奖励）
  • 同伴与社区：公开承诺 · 组队学习
  • 止损线与休整：防沉没成本绑架 · 防倦怠（精力管理与任务管理同权重）
P0

定向 —— 学前决策

为什么学 · 学到什么程度 · 花多少时间
  1. 三问定标：为什么学（内在/外在动机）？学到什么程度（了解 / 会用 / 精通 / 触及前沿）？时间预算与节奏（每周几小时 × 多少个月）？
  2. 写学习宪章（一页纸）：目标 · 验收标准（怎么算学成了，最好可检验）· 止损线（什么情况下允许放弃）· 节奏承诺
  3. 预演失败：如果三个月后放弃了，最可能的三个原因是什么？提前写对策

产 出

学习宪章（一页纸）

验收门 ⓪

一句话说清"为什么学 + 学到什么算成"，且验收标准可被第三方检验

常见坑

目标过大（"精通 XX"）；无验收标准；无止损线（沉没成本绑架）
P1

侦察 —— 信息搜集（画地图）

广度优先，先框架后细节
  1. 广度扫描：百科 / 高引综述 / 经典教材目录，至少 3 个独立来源交叉（防单源偏见）
  2. 画领域全景图：子领域划分 · 主流流派及分歧 · 经典问题 · 活跃前沿 · 标杆人物与机构
  3. 建术语表：50–100 个核心术语（新手最先撞上的墙就是黑话），逐步补"术语 ↔ 白话"对照
  4. 权威源分级：★★★ 核心教材/综述/标杆社区 · ★★ 专题深化 · ★ 补充扩展；记录每个源的可信度理由
  5. 搭信息管道：剪藏 / 稍后读 / RSS / 知识库 Inbox——让后续信息自动流向固定位置，而不是散落收藏夹

产 出

领域全景图 · 分级资源清单 · 术语表 · 信息管道

验收门 ①

能徒手画出领域地图；说出 3 个主流流派 / 经典问题；知道遇到问题该去哪个社区问谁

常见坑

陷入细节深挖（本阶段禁深读）；仓鼠症（只收藏不处理）；单源依赖
＝领域学徒·阶段一（侦察立法）
P2

筑基 —— 结构化输入（搭骨架）

把领域的概念网络装进自己脑子↩ 回 P1：发现资源缺口
  1. 分层阅读（自顶向下）：综述 → 教材主干 → 专题章节 → 一手文献。先通读主干建立框架，再按需下钻——不要从第一页线性读到最后一页
  2. 主动阅读（SQ3R 变体）：读前先写 3 个问题 → 带问题读 → 合上书自答 → 复述要点 → 隔日回顾
  3. 概念织网：卡片笔记（术语→概念→原理→方法，一卡一事）；定期画概念地图，把新概念挂到已有网络上（孤立知识点最易忘）
  4. 费曼自测：每学完一章，向假想的新人讲一遍；卡壳处标记回炉——这是"懂没懂"的唯一自检
  5. 间隔重复排程：核心概念制成卡片进入复习系统（1 天 / 3 天 / 7 天 / 21 天递进），对抗遗忘曲线

产 出

概念地图 · 知识卡片库 · 科普级领域讲解

验收门 ②

费曼测试：能向外行讲清领域核心概念及其相互关系，被追问三层不倒

常见坑

划线式假阅读（划了≠懂了）；收藏 = 学会的错觉；追求线性读完而非按需下钻
＝领域学徒·阶段一 SOP v1 + 数据基建（知识结构化入库）
P3

校准 —— 刻意练习（已知答案闭环）

用有标准答案的案例，量化"真懂了没"↩ 回 P2：错误归因为知识缺口
  1. 选已知答案案例集：教材习题 / 经典案例复现 / 有公认定论的问题——答案已知，过程要求与真实任务完全一致
  2. 独立作答：不看答案全流程走一遍（禁止边看边做，那是自欺）
  3. 对照打分 + 失效分析：每个错误归因到三类根因之一——知识缺口（回 P2）/ 方法缺陷（改流程）/ 熟练度不足（多练）
  4. 错题本：错误 → 规则。每条失效转化为显式规则，同类错误不犯第二次
  5. 难度爬坡：保持在约 85% 正确率的难度区间（太易无增长，太难则崩溃），逐级加码

产 出

校准报告 · 错题本（错误→规则）

验收门 ③

已知答案案例复现率 ≥80%（或领域公认线）；失效模式已全部转化为规则

常见坑

看答案再做（自欺）；只做舒服的题（舒适区滞留）；只对答案不归因
＝领域学徒·阶段二（盲测校准 + 验收组）
P4

实战 —— 项目驱动（真实产出）

在真实约束下做出完整作品↩ 回 P1/P2：实战暴露基础缺口
  1. 选真实约束项目：真实数据 / 真实受众 / 真实交付标准——规模适中但不是玩具
  2. 以终为始：先定义交付物（作品长什么样），倒推能力清单与学习需求——学的每一课都有明确去处
  3. 建反馈回路：行业标准对照 · 社区评审（把作品发到会被内行看到的地方）· 专家请教（带着具体问题去，不带"求指导"）
  4. 卡壳定向补课：允许并预期回环——实战暴露的缺口回到 P1/P2 定向补，而不是从头再学一遍
  5. 过程留档：决策日志（为什么这么做），它比结果更值钱——是 P5 创作的素材，也是复盘依据

产 出

完整作品 · 过程档案（决策日志）

验收门 ④

作品经得起行业标准 / 第三方评审（不是自我感觉良好）

常见坑

教程地狱（只看教程永远不开始）；完美主义拖延（憋大招）；无反馈裸奔
＝领域学徒·阶段四 RSI 循环（批量真实任务）＋ 阶段三（审查＝反馈回路制度化）

Part 3 · 同源映射：人类自学路径 ↔ 学徒 Skill两套流程本是同一套学习原理

通用路径（人类）领域学徒（AI）共同的学习科学原理
P0 定向（学习宪章）冷启动确认（领域 / 目标产出 / 验收谁定）自我调节学习·前思阶段（Zimmerman）：目标设定与策略规划
P1 侦察（画地图）阶段一 · 侦察立法（调研五件套，含知识总账）先行组织者（Ausubel）：先框架后细节，图式先行
P2 筑基（概念织网）SOP v1 + 数据基建（知识结构化入库）图式建构：新知挂上网络才留存；精细加工
P3 校准（已知答案闭环）阶段二 · 最小闭环（盲测 + 验收组）测试效应（主动回忆）＋ 合意困难（85% 规则）
反馈回路（老师批改 / 对答案）阶段三 · 审查对拍（制审分离 + 共识对拍）反馈回路 + 同伴评审（peer review）：外部校准防自欺
P4 实战（项目驱动）阶段四 · RSI 循环（批量真实任务）刻意练习（Ericsson）：真实场景 + 即时反馈 + 难度递增
P5 创造（教学与输出）成果沉淀 + 对外输出 + 诚实定性门徒效应（protégé effect）：为教而学，理解更深
S1 元认知（日志 / 复盘 / 三问）总进度文档 + 阶段门控 + 执行声明元认知监控（Flavell）＋ 自我调节学习·自省阶段
S2 知识管理（出处落地）铁律①：可核查性压倒一切生成效应 + 反幻觉：写下来并给出处，才真正 owned
错题本（错误→规则）铁律⑦：错误变制度（红线固化）错误驱动学习 / 超校正效应：高置信错误纠正后记得最牢

▎结论

领域学徒 Skill 不是"AI 特殊工作法"，而是人类成熟学习范式（自我调节学习 + 刻意练习 + 反馈回路）在 AI 上的工程化投影。反过来，通用自学路径也吸收了 Skill 实战中人类常规学习欠缺的机制：制审分离（自我批改无效，需独立视角）、已知答案量化验收（对抗"感觉学会了"）、错误变制度（错题本升格为流程红线）。

Part 4 · 通用性总结与领域特殊化备注主干领域无关，特殊性只在备注

▎八条通用模式（跨领域不变量，任何领域照此复现）

  1. 地图先行：广度优先扫描建立全景，再按需深钻（P1→P2）
  2. 结构化输入：分层阅读 + 概念织网，新知必须挂网（P2）
  3. 已知答案校准：用有定论的案例量化真懂程度，对抗自我感觉（P3）
  4. 真实项目产出：以终为始，学的每课有去处（P4）
  5. 输出倒逼输入：费曼检测贯穿，教学是最高形式的学习（P2/P5）
  6. 全程反馈回环：元认知 + 独立审查 + 共识对拍，外部校准防自欺（S1/门控）
  7. 错误变制度：错题本 / 红线固化，同类错误不犯第二次（P3/RSI）
  8. 知识可核查：一切结论与笔记落到出处，区分"我验证过"与"我听说的"（S2）
