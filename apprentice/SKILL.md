# 学徒 Skill（apprentice）

AI 进入任意陌生领域并达到"能独立产出经得起审查的成果"的四阶段标准作业程序。

方法论源自甲骨文 AI 辅助破译项目的完整实战复盘：六轮循环、145,072 字形全量入库、验收组 5/5 复现学术定论、21 卡独立盲审、两字确级认定。完整案例复盘见 `references/oracle-case.md`，可直接套用的文档模板见 `references/templates.md`。

## 何时用 / 何时不用

- **用**：用户要求 AI 中长期掌握一个陌生领域并产出成果——新学科、冷门技艺、交叉方向、行业研究后要动手干活的。
- **不用**：一次性问答式调研（查完即走，不建工作流、不做验收）；已有成熟 SOP 的常规重复任务。

## 第零步：阶段定位

触发本 skill 后，**先定位项目当前处于哪个阶段**，从对应阶段进入，不要从头重来：

1. 查目标工作区是否已有 `00-调研报告` / `01-工作流程设计` / `02-资源清单` / `03-文献调研` 等文档与 `研究档案/` 目录；
2. 有则读 `研究档案/00-总进度.md` 及三件知识资产（`知识总账.md` / `缺口登记簿.md` / `能力画像.md`，见"知识完整性与缺口管理"节），按其"下一步"与未销缺口续作；
3. 全无则从阶段一冷启动。冷启动时先与用户确认：领域名称、目标产出物、验收标准由谁定。

## 总览：双轨 × 四阶段与门控

skill 是**双轨结构**——通识轨负责"懂领域"（知识体系全谱覆盖），实战轨负责"会做事"（任务闭环与成果产出），两轨强制互喂：

```
通识轨（懂领域）：领域课程六类模块 → 学习循环 学→织→测→联（概念卡/费曼/自测/跨模块联系）
      ║ 互喂：模块知识喂实战证据链；实战发现的缺口回课程补模块
实战轨（会做事）：四阶段 侦察立法 → 最小闭环 → 审查对拍 → RSI自循环（原主体，全保留）
```

**实战轨四阶段**（原主体不变，每阶段嵌入对应通识轨任务）：

```
阶段一 侦察立法          阶段二 最小闭环          阶段三 审查对拍          阶段四 RSI自循环
──────────────         ──────────────         ──────────────         ──────────────
领域现状报告            材料/数据基建入库        独立审核（制审分离）      目标池排序（先易后难）
资源清单               盲测校准（匿名已知答案）    行业共识对拍            批量作业→审核→整改
专家方法论体系     →     验收组全流程跑通     →    系统性问题整改      →    教训固化为新红线
工作流v1（SOP）         失效模式→规则转化        红线固化进SOP           规则升级→目标池更新
AI分工定位+接口预留      SOP升级v2（证据分级）     诚实定性（复现≠新发现）   循环N轮，成果沉淀
```

**门控铁律：上一阶段双轨 DoD 均未达标，不得进入下一阶段。** "可控"二字就体现在门上——每阶段有一票否决式的验收条件，不达标就留在本阶段修，不带病升级。

| 阶段 | 实战轨 DoD（放行条件） | 通识轨 DoD | 典型时长 |
|---|---|---|---|
| 一 侦察立法 | 五件套齐备（现状报告/资源清单/方法论体系/SOP v1/**知识总账**），SOP 每步有输入/输出/工具/执行者 | **领域课程表建成**：六类模块齐、学习顺序定、资源挂接到模块 | 1 轮会话 |
| 二 最小闭环 | 验收组量化达标（已知答案复现率 ≥80% 或与用户约定线），失效模式已转化为规则，SOP 升至 v2 | **基础概念＋方法模块学毕**：概念卡入库、模块自测 ≥80%、费曼讲解通过 | 1–2 轮会话 |
| 三 审查对拍 | 独立审核通过、与行业共识对拍完成、红线清单固化、诚实定性报告出具 | **流派与公案模块学毕**：能向审核者讲清领域地图、学派分歧与定论/争议边界 | 1 轮会话 |
| 四 RSI循环 | ≥2 轮完整"作业→审核→规则升级"循环，累计成果档案+总进度文档在案 | **前沿模块＋知识巡检制度**：领域动态跟踪（领域是活的，课程表持续更新） | 不限，持续 |

## 通用铁律（全阶段有效，先读后干）

1. **可核查性压倒一切**：每个结论必须落到可核查的原始材料（著录编号、出处、图片、数据行）。LLM 凭训练记忆写出的"证据"一律标"待核对"，禁止当作硬证据使用。
2. **SOP 从行业共识翻译而来，不由 AI 发明**：先文献调研搞清领域顶尖从业者靠什么证据下结论、证据如何加权，再把它映射为 AI 可执行的检索+推理步骤。行业方法在前，AI 加速在后。
3. **已知答案验收是唯一硬标准**：判断"AI 是否真懂了"，不看它说得像不像，看它能否用与真实任务完全相同的流程，把已有公认答案的案例独立做对。
4. **先易后难**：目标池按产出概率排序——最接近已知形态的、证据最丰富的先做；最难的孤例最后碰或不碰。
5. **置信分档输出**：结论永远带分级置信度（确/较可信/存疑/弱假说/存而不论），禁止二值断言。降档不可耻，overclaim 才是事故。
6. **淘汰不丢**：被否的候选/假设连同否因归档（"已排除假设"节），防止后续重复劳动。
7. **错误变制度**：每次审核发现的系统性问题，整改后必须固化为红线写进 SOP。同类错误不允许犯第二次——这是 RSI 的实质。
8. **诚实定性**：复现已知答案 ≠ 新发现。对外输出成果前必须做前人工作核查，并明确标注哪些是复现、哪些是增量。
9. **对拍先于发布**：任何结论成型后、发布前，先与已发表成果/权威数据逐条对拍。假说被对拍推翻（如甲骨文 gx21 案例）是流程在起作用，不是失败。
10. **来源三级标注**：每条论断标〔已验证·有出处〕/〔模型记忆·待核对〕/〔未知·缺口〕；"未知"必须显式声明，禁止用模型记忆填充冒充知识（详见 `references/knowledge-coverage.md`）。
11. **能力边界自知**：未测试的任务类型＝能力未知。接任务先查能力画像与答前门控三问，超纲即降档并触发补缺，禁止硬答。
12. **案例是学习仪器，不是学习目的**：每个单案实战结束必须回喂领域课程（更新相关模块的概念卡与地图）；每个课程模块学完必须有实战或应用出口。禁止"只会做题不懂领域"，也禁止"懂名词不会干活"。

## 通识学习轨：领域课程与学习循环

实战轨解决"会做这类任务"，通识轨解决"懂这个领域"——两者缺一，学习都是收敛的。通识轨的核心资产是**领域课程表**（`研究档案/领域课程表.md`），把领域知识体系拆为**六类标准模块**：

| 模块类 | 内容 | 学完的标志 |
|---|---|---|
| ① 基础概念 | 对象与范围、术语体系、基本分类 | 能给外行下定义并举例/反例 |
| ② 理论与方法 | 核心原理、主流方法及其适用域与失效条件 | 能说清"什么问题用什么方法、为什么、何时失效" |
| ③ 工具与实践 | 行业怎么干活：工具链、工作产物、流程惯例 | 能走通一遍最小实践 |
| ④ 历史与流派 | 学科史、学派分歧及分歧根源、人物与机构 | 能画出流派谱系并讲清分歧点 |
| ⑤ 经典案例与公案 | 定论案（共识怎么形成的）＋争议案（争议卡在哪） | 能复盘定论的证据链、复述争议双方论据 |
| ⑥ 前沿与开放问题 | 活跃方向、未解问题、领域正在争论什么 | 能列出 3+ 个开放问题及为什么未解 |

**模块学习循环（每模块走一遍，提示词模板见 `references/learning-prompts.md`）**：

```
学（分层输入：综述→教材章节→专题，带 3 个问题读）
 → 织（概念卡增量入卡库；领域知识地图挂网更新）
  → 测（模块自测：自生成考题对答案 ≥80% ＋ 费曼讲解卡壳点清零）
   → 联（跨模块联系：与已学模块的连接/冲突；与实战轨的双向回喂）
```

模块状态四态：未学 → 在学 → 待测 → 已通过（自测+费曼双过才算）。课程表本身滚动演进——阶段四的巡检同时巡课程（新概念新方法新公案入模块）。

> 模块学习循环中的"学＋测"两步可由外挂插件 **`lrv-loop`（学述验闭环）**驱动执行：学习→**合卷复述**→比对验证的 ReAct 式内化引擎，验证基准按期别从行业共识（E）演进到已验证自库混合（M）再到自主结论（L）。见"外挂组件接入"节；未安装该插件时按 `references/learning-prompts.md` 模板手工执行同等协议，流程不变。

**与知识总账的分工**：总账（toolbox 管理）回答"领域知识空间覆盖了没有"（供应侧盘点，三态）；课程表回答"作为学习者学到什么程度"（学习过程，四态）。总账的未覆盖区经定级后进入课程表成为待学模块；课程表学毕的模块回总账销覆盖债。

## 阶段一：侦察与立法（调研固化 SOP）

**目标**：广泛信息搜集 + 文献调研，把领域通用研究方法和研究过程固化为标准 SOP，预留 AI 拓展方向和接口。

产出五件套（前四件骨架见 `references/templates.md`，第五件见 `references/knowledge-coverage.md`）：

1. **`00-调研报告-<领域>现状.md`**——领域全景：现状与难点（为什么难、难在哪）、已有工作全景（前人怎么干、哪些已被做掉）、AI 能做什么/不能做什么。最后一条是重点：明确 AI 的独特价值定位（通常是"全量材料的机器检索与组合推理"——人记不住全量，AI 可以系统化地做），以及人机分工边界（AI 产候选+证据链，人做最终裁决）。
2. **`02-资源清单.md`**——数据集、平台、工具、关键文献的下载地址与许可证，按优先级分级（★★★核心/★★支撑/★补充）。
3. **`03-文献调研-<领域>方法论体系.md`**——领域判别论据体系：顶尖从业者下结论靠什么证据？各类证据权重如何？找 2–4 个标杆案例做证据链解剖（每个案例逐步拆解"关键一步靠什么证据完成的"）。这是 SOP 的灵魂——后续工作流的每个环节都从这里翻译。
4. **`01-工作流程设计.md`（SOP v1）**——端到端工作流，拆为若干阶段，每阶段写明：输入→输出、用什么工具、由谁执行（人工/AI/人机协同）。附固定作业模板（提示词模板或操作模板）。
5. **`研究档案/知识总账.md`（供应侧完整性）**——找到领域的权威普查工件（教材目录/考纲/分类法总录/数据集类目/招聘JD聚类/社区FAQ等），逐区展开为知识清单并三态标记（已覆盖/部分/未覆盖），算出覆盖率；同时建**任务空间地图**（任务类型×难度三档：已知答案/争议/开放）。这是"搜到的行业知识完整吗"的唯一可操作度量——绝对完整不可保证，相对普查工件的覆盖率必须自知（详见 `references/knowledge-coverage.md`）。
6. **（通识轨）`研究档案/领域课程表.md`**——按六类标准模块拆解领域知识体系，定学习顺序（基础概念→方法→工具→流派→公案→前沿），把资源清单逐项挂到模块；总账的未覆盖高阻塞区直接转为待学模块。

**AI 扩展接口预留**（用户核心要求，本阶段必须显式落笔）：

- **数据接口**：一切原始材料结构化入库（SQLite/向量索引/结构化文件），使所有证据可机器检索、可复核——这是后续一切 AI 加速的地基；
- **工具接口**：预处理/检索用一次性脚本放 `scripts/`（现写现跑，不服务化、不做常驻 agent）；
- **记忆接口**：跨会话经验沉淀到进度文档（项目内）与 mem0（用户级长期记忆，`memory_add` 记录可复用的领域经验）；
- **分工接口**：SOP 每步标注人工/AI/协同，后续阶段逐步把人工步骤自动化。

**红线**：本阶段禁止动手做真实任务（手痒先忍住）；调研引用必须附来源链接。

## 阶段二：最小闭环（盲测 + 验收）

**目标**：找典型案例验证 SOP，跑通一个最小闭环，让 AI 开始真正理解和掌握领域工作流程。

1. **材料基建**：下载核心数据集，预处理入库（清洗、切分、元数据、检索索引）。入库即写统计报告（多少条、什么结构、质量坑有哪些）。数据质量发现（如标注混装、检索对某类失效）本身就是第一份领域知识。**无结构化数据的领域**（纯技艺、实操类）：降级为"工件库"模式——收集代表作/案例/操作记录作为语料，检索基建退化为文档全文检索，流程其余部分不变。
2. **盲测校准**：取一批已知答案的样本，匿名打乱，让 AI 用当前 SOP 独立作答，量化命中率。**重点不是分数，是失效模式**——每个错误逐条分析根因，转化为新规则写进 SOP。甲骨文案例：盲测 80% 命中，"草化变形""部件误辨"两类失效直接催生了"辞例语境提为裁决性证据"的 v2 升级。
3. **验收组设计**：选 3–5 个已有公认标准答案的典型案例（学界定论/行业标准/权威数据），用与真实任务**完全相同**的流程走一遍，最后一步多出"对照标准答案打分"。验收组与实战组（真未知目标）并行建档，方法完全一致，只有最后对照不对照的区别。
4. **SOP 升级 v2**：吸收盲测与验收的教训，通常的核心升级是**证据分级加权**——把领域方法论体系（阶段一第 3 件）里的证据类目落成"权重表 + 裁决规则"（哪类证据是裁决性的、哪类是入门券、几类独立支持才能立案、一条硬反证即否案）。
5. **能力画像初版**：把盲测/验收通过率按任务类型×难度记入 `研究档案/能力画像.md`，未测试类型标"❓未知"——从第一天起就养成"知道自己不知道什么"的习惯。
6. **（通识轨）基础概念＋理论方法模块学习**：按课程表开课——模块学习循环（学→织→测→联），概念卡入库、模块自测 ≥80%、费曼讲解通过。与实战轨并行推进：基建跑数时读书，验收等结果时织网。

**门**：验收组复现率 ≥80%（或与用户约定线）。不达标 → 回到 SOP 修规则再来，禁止降低验收标准放行。

## 阶段三：审查与对拍（出师考核）

**目标**：可控的人工审查完成一整个基础任务，与行业共识对照，确保 AI 真正理解行业内容、经验与知识召回正确。

1. **独立审核（制审分离）**：另起一个独立审核代理（或独立会话），审核规则：
   - 审核者**禁止采信档案文字**，必须从原始数据/原始材料独立查证每条证据；
   - 审核者与制档者分离，**禁止自我放行**；
   - 产出审核报告：通过/需修订逐卡列出，重点揪三类系统病——证据描述与原始材料不符、引文加工/选择性引用、置信度 overclaim。
2. **整改与红线固化**：逐条整改审核意见，然后把系统性问题固化为红线补进 SOP。甲骨文案例固化的五条红线（可直接泛化）：①看图/看数据类描述必须二次独立核对；②残缺数据禁止补写，省略必须显式标注；③每份档案强制展示主导模式（前 N 搭配/前 N 特征），禁止选择性引用少数支持例；④判定前必须调取同源完整上下文（同版/同批/同源全量）；⑤一切档案经独立审核后方可定稿。
3. **行业共识对拍**：把已认定的结论与领域已发表的权威成果逐条对拍。对拍可能推翻自己的结论——被推翻就改，并且把教训固化（甲骨文教训："对拍必须先于假说发布"）。
4. **诚实定性报告**：明确写出哪些结论是已知答案的复现/归位（机制验证价值，不算新发现）、哪些是真正的前人未做增量、距离行业认可的标准（如发表/申报）还差什么（差距清单）。
5. **（通识轨）流派与公案模块学习＋领域图景考核**：学毕④⑤类模块；审核环节加一道"领域讲解"——被审核方能向审核者徒手讲清领域地图、学派分歧、定论与争议的边界，讲不清＝通识轨未达标，与实战审核同门处理。

**门**：独立审核通过（无未整改的系统性问题）+ 对拍完成 + 定性报告出具。此门过后 AI 才算"出师"，才有资格进入无人值守的 RSI 循环。

## 阶段四：RSI 自循环（出师执业）

**目标**：AI 自己 loop 多轮做行业学习与开发，每轮产出真实成果，经验与知识持续沉淀，最终得到完整结果。

**单轮循环结构**（每轮必含全部四步，缺一即退化为准 RSI）：

```
选目标（目标池按产出概率重排）
  → 批量作业（按 SOP v2+ 逐案建档，一案一档）
    → 独立审核（制审分离不放松，审核率可随信任度从全查渐降至抽查）
      → 规则升级（本轮教训固化为新规则/红线，目标池与差距清单更新）
```

要点：

- **目标池动态排序**：每轮结束按"证据缺口最小优先"重排；被否目标保留在池中标明否因。
- **分层抽测（防幸存者偏差）**：每轮按任务类型配额抽测，不许只做池里最易的——否则能力画像被"只会做一类题"污染；抽测结果更新能力画像。
- **覆盖巡检**：每 N 轮重跑权威普查工件 diff（覆盖率复查）、清点缺口登记簿燃尽情况；任务失败与权威源分歧一律登记为覆盖债，不许只修个案。
- **每案回喂课程（铁律⑫的执行点）**：每案结档时强制更新相关课程模块的概念卡与知识地图——批量案例的复利不只在于产出，更在于喂出越来越完整的领域课程。
- **通识轨持续**：前沿模块学习＋知识巡检（领域是活的：新文献/新方法/新公案定期入课程表）；课程表未覆盖的领域动态登记为缺口。
- **方法论突破即时制度化**：循环中偶然发现的新通道（如甲骨文项目确证"H 编号＝《合集》编号"对拍通道）要立刻写进 SOP 变成全量能力，而不是留作个案技巧。
- **审核率阶梯**：初期全查 → 稳定后抽查验 → 高置信结论可凭外证直接认定，但制审分离永不取消。
- **成果沉淀三件套**：单案研究档案（一案一档，含已排除假设）、每轮小结、`00-总进度.md` 滚动更新（累计战果+下一步+差距清单）。
- **跨会话记忆**：可复用领域经验同步进长期记忆系统（如 mem0，`memory_add`）；有个人知识库蒸馏管道的环境，可把原始材料投 Inbox 走蒸馏。
- **对外成果**：攒够规模后按行业认可的格式整理终稿（甲骨文对应文字博物馆悬赏论证报告格式），并保留诚实定性。

## 知识完整性与缺口管理（贯穿机制，防乱答与主动补缺）

会做已搜到的题 ≠ 获得行业能力。行业能力 = 任务空间（类型×难度）覆盖面 + 对未覆盖区的自知。完整机制见 `references/knowledge-coverage.md`，要点：

- **知识七形态**：行业知识以七种形式存在（SOP/方法论/语料库/案例档案/红线/元知识/**模型权重**），前六种显性可审计，只有第七种（模型隐性记忆）不可证——**乱答全部来自它**，对策是逼每条论断声明来源；
- **三级来源标注**：〔已验证·有出处〕/〔模型记忆·待核对〕/〔未知·缺口〕；知识不足时合法输出只有降档作答、存而不论、缺口卡三种，自信完答被禁止；
- **答前门控三问**：这类任务画像里测过吗？依赖知识在总账覆盖了吗？哪些论断只是模型记忆？
- **缺口驱动学习循环**：覆盖巡检 → 缺口登记（缺什么/信号源/怎么补/成本/阻塞面）→ 定级 → 补缺动作映射 → 缺口区自生成考题复测销账。未知未知靠对外暴露（专家审查/社区发布）探测。

## 配套工具箱（组件层：结构化资产的机械执行体）

**结构化输入输出的实现者分层**：skill 本体（markdown 协议）只约定格式，靠会话内 LLM 自律执行；真正的结构化存储历史上发生在各领域项目层（如甲骨文项目的 SQLite+脚本，随用随建）。为避免三件知识资产跨会话"格式漂移、聚合靠手数、门控靠自觉"，skill 自带轻量工具箱：

- 位置：`scripts/da_toolbox.py`（单文件，仅标准库，SQLite 为真相源，markdown 为渲染视图）
- 核心命令：`init`（初始化资产）｜`coverage set`（总账登记）｜`gap add/list/start/close/shelve`（缺口流转）｜`profile record`（画像记录）｜**`gate <任务类型>`（答前门控三问的机械执行体，裁决三态：放行 exit0 / 降档 exit1 / 阻塞 exit2）**｜**`check <研究卡>`（卡片机械校验：必备节/置信词表/三级标注，过了再交独立审核，省出审核注意力给语义层）**｜`stats`（覆盖率/燃尽率/画像汇总）｜`render`（重渲视图）
- 约定：三件资产的改动一律走命令（状态词表封闭枚举：缺口四态/覆盖三态/难度三档）；渲染出的 .md 文件头带自动生成标记，禁止手改
- **组件化触发条件（不过度工程）**：卡片 ≤20 且 RSI <3 轮时，markdown+自律够用；卡片 >20 或审核第二次发现格式类问题或需要跨会话聚合统计时，启用本工具箱；领域数据层组件（语料入库/检索脚本）仍按各领域需要随建，不进 skill。

## 外挂组件接入（插件架构）

**设计原则：本体稳定，扩展外挂**。apprentice 的核心流程（双轨四阶段/铁律/门控）保持稳定，新能力以独立插件 skill 接入——每个插件自带完整协议与工具、可独立使用，缺席时 apprentice 走降级路径，主干文档不因插件存在与否而改变。

| 插件 | 功能 | 接入点 | 缺席降级 |
|---|---|---|---|
| **`lrv-loop`（学述验闭环）** | 学习(Learn)→合卷复述(Restate)→比对验证(Verify) 的最小内化引擎；验证基准期别演进：E 共识期（权威源）→ M 混合期（已验证自库＋共识）→ L 自主期（自主结论＋矛盾升级条款）；`scripts/lrv.py` 机械强制解锁（M 需 ≥2 模块经共识验证通过，L 需 ≥5＋本模块有 M 履历） | 通识轨模块学习循环的"学＋测"两步；LRV 轮次产物回喂：通过复述稿→课程表"已通过"依据、未销失配→缺口登记簿、轮次统计→能力画像、新概念→概念卡库 | 按 `references/learning-prompts.md` 模板二/三/四手工执行同等协议（自测＋费曼），流程不断 |

**插件接口规范**（后续插件照此办理，防止覆盖式开发）：
1. 独立 skill 目录（自带 SKILL.md＋scripts），可脱离 apprentice 单独运行；
2. 显式声明接入点（挂到 apprentice 哪个环节）；
3. 显式声明产物回喂映射（写入哪些 apprentice 资产）；
4. 显式声明缺席降级路径（插件不在时 apprentice 怎么办）；
5. **不得修改 apprentice 主干文档**，只经由本节登记接入。

## 与人类自学路径的同源关系

本 skill 四阶段是人类成熟学习范式（自我调节学习 + 刻意练习 + 反馈回路）的工程化投影：侦察立法＝画地图与搭骨架，最小闭环＝已知答案的刻意练习，审查对拍＝老师盲批与对答案，RSI 循环＝项目驱动实战 + 错题本升格为制度。完整的通用自学路径（P0 定向→P1 侦察→P2 筑基→P3 校准→P4 实战→P5 创造 × 元认知/知识管理/动机精力三支撑系统）见 `references/universal-path.md`——当用户要的是"人怎么从零学一个领域"而非"AI 作业流程"时按该手册走；两套可互相翻译，映射表见手册末尾。
